# แผนทำหน้าฝึกสำหรับเด็กจากไวร์เฟรม

ไวร์เฟรม [`docs/design/wireframes/kid-practice.html`](design/wireframes/kid-practice.html) ผ่านการอนุมัติแล้ว (23 พ.ย. 2569) เอกสารนี้แปลงไวร์เฟรมเป็นงานในโค้ดจริง ทำทีละขั้น แต่ละขั้นจบด้วยการตรวจและ commit แยก

## หลักการ

1. **ไม่แตะหลังบ้าน:** หลักสูตร, รูปแบบข้อมูล `Session` / `Attempt`, การบันทึกในเครื่อง, การส่งผลเข้าศูนย์ประเมิน (`submitStudioAssessment`) และ AI ตรวจเสียง ใช้ของเดิมทั้งหมด หน้าใหม่เปลี่ยนแค่วิธีแสดงผลและวิธีรับคำตอบ
2. **ใช้ตรรกะเดียวกับหน้าเดิม:** ดึงการอัดเสียงและการบันทึกออกจาก `Practice` เป็น hook ให้หน้าเดิมและหน้าใหม่ใช้ร่วมกัน ผลที่บันทึกจึงเหมือนกันทุกประการ
3. **มีทางกลับ:** ระหว่างทยอยปล่อย ผู้ใหญ่สลับ "หน้าแบบเดิม" ได้จากเมนูผู้ใหญ่ ค่าเริ่มต้นเป็นหน้าใหม่เมื่อจบเฟส 1
4. **ทุกข้อเล่นได้ตั้งแต่วันแรก:** ข้อที่ยังไม่มีเกมเฉพาะใช้การ์ด "พูดเลย" แบบเรียบ (ภาพ + คำ + ปุ่มพูด) ไปก่อน แล้วค่อยเปลี่ยนเป็นเกมในเฟสถัดไป

## สิ่งที่พบในโค้ดตอนนี้

- ห้องฝึกเปิดที่ `/training` ผ่าน `LearningStudioClient` → `LearningStudio` (ไฟล์เดียว 2,837 บรรทัด) ภายใน `AppShell` ของเว็บ
- หน้าฝึกคือ `Practice` (บรรทัด ~1553–2190) รวม 3 เรื่อง: อัดเสียง (MediaRecorder), บันทึก Attempt + ส่งเข้าศูนย์ประเมิน, และ UI
- เส้นทางใช้ hash (`#home`, `#path`, `#practice`, `#summary` …) เก็บสถานะใน localStorage ต่อเด็ก
- CSS ของห้องฝึกผ่าน `npm run learning:prepare` ซึ่งปรับสีและขนาดตัวอักษรอัตโนมัติ → CSS ของหน้าเด็กต้องแยกไฟล์ ไม่ผ่านขั้นนี้
- เสียงพี่ปูเล่นได้เฉพาะประโยคที่มีไฟล์ใน catalog (`useSpeaker`) ประโยคใหม่ของพี่ปูต้องสร้างเสียงก่อน (Gemini Sulafat, โควตาวันละ 10 ครั้ง)
- ศูนย์ประเมินรับผลผู้ใหญ่ (`adultReview`) เฉพาะข้อ observation ข้อพูดบันทึกเป็น "รอผู้ใหญ่ตรวจ" แล้วผู้ใหญ่ตรวจในหน้าตรวจผลเดิม → ปุ่มผลของผู้ใหญ่ในหน้าใหม่บันทึกลง `Attempt.review` เหมือนหน้าตรวจผลเดิม
- เทสต์ `npm run learning:test` ตรวจโดเมน หลักสูตร เสียง และข้อความบางส่วนในซอร์ส (ห้ามใช้ `document.body.classList` ใน `LearningStudio.tsx`)

## จับคู่ข้อฝึกกับเกม

| ข้อฝึก | เกม | ใช้กับ |
|---|---|---|
| `choice` | ส่งของให้พี่ปู (เดิม: ป้อนอาหาร) | ฟังแยกเสียง, เข้าใจคำจากภาพ, เสียงกับตัวอักษร |
| `speech` + ภาพปาก | กระจกวิเศษ | ดูปากและพูดตาม |
| `speech` + `segments` | กระโดดหิน | ฝึกพยางค์, ผสมพยางค์ |
| `speech` คำเดียว | การ์ดสติกเกอร์ | ฝึกคำ, อ่านคำ |
| `speech` วลี (ตัดคำด้วย `Intl.Segmenter("th")`) | รถไฟคำ | วลีและประโยค, บอกความต้องการ, เล่าเรื่อง |
| `observation` | เล่นกับผู้ใหญ่ (พี่ปูซ่อนแอบเมื่อภาพเป็นกล่อง) | ลองใช้จริง |

- ช่วงนี้ หิน การ์ด และรถไฟ ยังเป็นแบบเรียบ (ชิปคำ/การ์ดภาพ) ตามหลักข้อ 4 จะเปลี่ยนเป็นเกมเต็มในเฟส 2–3

### รอบแก้ตามรีวิว (23 พ.ย. 2569)

ผลรีวิวจากการลองเล่น: ของในเกมป้อนอาหารไม่ใช่ของกิน, คำชมโดนตัด, ไม่มีเอฟเฟกต์, หินและรถไฟยังไม่เป็นเกม, ภาพดูไม่ออก

- **ส่งของให้พี่ปู** (แทนป้อนอาหาร): ภาพที่แตะบินไปหาพี่ปู ของกินพี่ปูกิน (ง่ำ ง่ำ) ของอื่นลงตะกร้า มีพลุและดาว · ผิดครั้งแรกพี่ปูส่ายหัว ผิดครั้งที่สองชี้ภาพที่ถูกแล้วพูดคำให้ฟัง
- **รอคำชมจบก่อนไปข้อต่อไป:** `useSay().say()` คืน promise ที่จบเมื่อพี่ปูพูดจบ (มีตัวกันค้าง: เสียงหยุด 0.6 วินาที หรือรอนานสุด 6 วินาที)
- **กระโดดหิน (2.1) และรถไฟคำ (3.1) เป็นเกมจริงแล้ว:** ได้ยินเสียง 1 ช่วง = ปูกระโดด 1 ก้อน / ต่อตู้ 1 ตู้ (นับช่วงเสียงในเครื่อง ไม่ตัดสินว่าถูกผิด) · ครบแล้วปูขึ้นฝั่งพร้อมพลุ / รถไฟเป่าหวูดปู้น ปู้น วิ่งออกไปแล้ววนกลับ · ประโยคยาวรวมคำเป็นไม่เกิน 4 ตู้ · พูดไม่ครบในครั้งเดียว กดพูดต่อได้ ครบ 3 ครั้งถือว่าข้ามแล้ว · โหมดแตะจอแตะ 1 ครั้ง = 1 ก้อน
- **การ์ด:** ตอบแล้วการ์ดส่ายและมีพลุ · **เสียงเอฟเฟกต์** สร้างด้วย Web Audio (ไม่เล่นขณะไมค์อัด กันไมค์นับเป็นเสียงเด็ก)
- **ภาพใหม่ทั้งชุด** (`Art.tsx`, `SceneArt.tsx`): การ์ตูนมีเส้นขอบ แสงเงา รายละเอียดพอให้รู้ว่าเป็นอะไร ตรวจทั้งพื้นสว่างและมืด
- **โหมดลดการเคลื่อนไหว** (เปิดเองเมื่อปิดแอนิเมชันของ Windows): เก็บการเคลื่อนไหวสั้นที่เป็นคำตอบของเกมไว้ หยุดเฉพาะที่วนซ้ำเป็นพื้นหลัง
- **บั๊กที่แก้จากการตรวจโค้ด:** กดพักระหว่างส่งผลแล้วรอบเดินต่อเอง · Space ไปกดปุ่มพัก · ไมค์อัดค้างเมื่อปุ่มไมค์หายกลางทาง/สลับหน้าต่าง · เลื่อนหน้าไม่ได้หลังกด Back ตอนเปิดจอเริ่มรอบ · "กลับไปใช้ไมค์" ไม่ทำงาน · ไมค์ใช้ไม่ได้แบบอื่นไม่บอกอะไร · ทดสอบไมค์ไม่ผ่านแล้วไม่เปลี่ยนเป็นแตะจอ · ไม่บันทึกว่าได้ฟังตัวอย่าง (`support: modeled`) · เมนูผู้ใหญ่ไม่จับโฟกัส · AudioContext ไม่ resume บน iOS · เด็กเสียงเบาที่พูดทันทีไม่ถูกนับ · Back จากจอฉลองไปเจอหน้าว่างแบบเดิม
- ตรวจแล้ว: เทสต์ทั้งหมด (`test-kid.mjs` 8 ข้อ), `tsc`, `eslint` · ลองในเบราว์เซอร์ (มือถือและคอม) ทั้งแตะจอ และ**ไมค์จำลอง** (Edge headless ที่ไมค์ปลอมส่งเสียงบี๊บเป็นช่วงๆ): ปูกระโดดตามเสียง รถไฟต่อตู้ตามเสียง ได้ไฟล์เสียงหลังปล่อยปุ่ม
- **ยังไม่ได้ลอง:** เสียงเด็กจริงบนเครื่องจริง (คอม, Android Chrome, iOS Safari)

## ความเสี่ยงและเรื่องที่รอ

- **เสียงพี่ปูประโยคใหม่:** ระหว่างรอไฟล์เสียง หน้าเด็กแสดงข้อความในลูกโป่ง และเล่นเสียงเดิมที่มีอยู่ (คำฝึก, คำชม) ไม่ขึ้นข้อความเตือนว่าไม่มีเสียง
- **ภาพปาก:** ใช้แบบผสมตามข้อเสนอ ถ้าทีมเลือกแบบอื่น เปลี่ยนได้ในไฟล์เดียว (`mouths.tsx`)
- **ไมค์บนมือถือ:** Safari บน iOS รองรับ MediaRecorder ตั้งแต่ 14.3 ต้องลองบนเครื่องจริงก่อนปล่อย
- **ผลผู้ใหญ่ของข้อพูดในศูนย์ประเมิน:** ตอนนี้ศูนย์ประเมินบันทึกข้อพูดเป็นรอตรวจ ถ้าต้องการให้ผลจากแถบผู้ใหญ่เข้าศูนย์ทันที ต้องเพิ่มใน API ภายหลัง
- **ห้ามแตะ:** branch `main` และ Supabase production
