# งานที่ยังไม่ได้ทำและต้องทำต่อ

> อัปเดต 21 พฤศจิกายน 2026 · บรานช์ `sky` · ผู้ทำ: Peeranatz
> รายละเอียดระบบประเมินอยู่ใน [assessment-handoff.md](assessment-handoff.md)

## สถานะตอนนี้

- **ตัวตรวจเสียงด้วย AI:** เปลี่ยนจาก Azure มาใช้ **OpenAI** เพราะสมัคร Azure ไม่สำเร็จ ตัวเชื่อมเสร็จและทดสอบด้วยข้อมูลจำลองแล้ว แต่พี่บาสยังจ่ายเงินค่า OpenAI ไม่ผ่าน (21 พ.ย.) จึงยังไม่มีคีย์
- **สรุปรอบด้วย Claude (ใหม่ 21 พ.ย.):** ระหว่างรอ OpenAI ใช้ Claude เขียนสรุปตอนจบรอบให้ผู้ใหญ่ ดู[หัวข้อ 1A](#1a-เปิดสรุปรอบด้วย-claude) Claude ฟังเสียงไม่ได้ ข้อพูดยังให้ผู้ใหญ่ตรวจเหมือนเดิม
- **ชุดทดสอบ:** ทดสอบรายขั้นครบ 432 กิจกรรมรวมสรุปรอบด้วย Claude ผ่าน 598/598 checks (ฐานข้อมูล OpenAI และ Claude จำลอง) unit test ผ่าน 14/14 typecheck, lint และ build ผ่าน
- **ทดสอบหน้าเว็บในเครื่อง:**
  - ข้อเลือกตอบของเด็กครอบครัวและเด็กโรงเรียนถูกบันทึกเข้าศูนย์ และขึ้นในหน้าความก้าวหน้าและรายงาน
  - แท็บ "รอตรวจ" ของครูเปิดได้
- **บั๊กที่แก้ในรอบนี้:**
  - เลือกเด็กโรงเรียนแล้วโหลดหน้าใหม่ ระบบเด้งกลับไปเด็กของตัวเอง
  - ข้อพูดที่อัดเสียงแล้วแต่ไม่ได้กดส่งตรวจ ไม่ถึงคิวของครู
  - ข้อความเรื่อง AI และการอัปโหลดเสียงในหน้าแรก หน้าเข้าร่วม ห้องฝึก และนโยบายความเป็นส่วนตัว จะผิดทันทีที่เปิด AI จึงเขียนใหม่ให้ถูกทั้งตอนปิดและเปิด AI
  - ชื่อเด็กในห้องฝึกและแถบด้านบนไม่ตรงกับตัวเลือกเด็ก
  - ป้าย "ผู้ใหญ่ตรวจ" ของขั้นที่ตรวจจากเฉลย

## 1A. เปิดสรุปรอบด้วย Claude

**ทำงานอย่างไร:** หน้า "สรุปรอบ" มีการ์ด "คำแนะนำจาก Claude" ให้ผู้ใหญ่กดขอ
- Claude เขียนคำชมให้เด็ก สิ่งที่ทำได้ดี สิ่งที่ควรฝึกต่อ และกิจกรรมฝึกที่บ้าน 2 อย่าง
- เบราว์เซอร์ส่งเฉพาะรหัสข้อและผลแต่ละข้อ เซิร์ฟเวอร์ค้นชื่อขั้นและคำเป้าหมายจากหลักสูตรเอง
- Claude **ไม่ได้รับ** ชื่อเด็ก รหัสเด็ก รหัสรอบ เสียง หรือข้อความที่พิมพ์จากหน้าเว็บ
- รอบเดิมที่ผลไม่เปลี่ยนจะได้สรุปเดิมจากฐานข้อมูล ไม่เรียก Claude ซ้ำ จำกัด 5 สรุปใหม่ต่อคนต่อนาที

**ขั้นตอนเปิดใช้:**
1. เปิด Docker Desktop แล้วติดตั้ง migration `20261121000100_assessment_round_summaries.sql` ในฐานของเครื่อง
2. ใส่คีย์ Anthropic ต่อจาก `ASSESSMENT_ANTHROPIC_API_KEY=` ใน `.env.local`
   - ใช้ชื่อนี้แทน `ANTHROPIC_API_KEY` เพื่อไม่ให้ชนกับ Claude Code หรือเครื่องมืออื่นในเครื่อง
   - API key ปกติจาก Claude Console ขึ้นต้นด้วย `sk-ant-api…`
3. รัน `npm run assessment:check-claude` ต้องขึ้น `✓ คีย์ใช้งานได้` (เรียกดูข้อมูลโมเดลเท่านั้น ไม่เสียเงิน)
4. รัน `npm run dev` ใหม่ แล้วเข้า `/platform/assessment`
   - ต้องเห็น "Claude สรุปรอบ · ตั้งค่าแล้ว"
   - เปิดสวิตช์ "สรุปรอบด้วย Claude" → บันทึกฉบับร่าง → เผยแพร่
5. ฝึกให้จบหนึ่งรอบด้วยบัญชีผู้ปกครองทดสอบ แล้วกด "ขอคำแนะนำจาก Claude" ที่หน้าสรุปรอบ

**โมเดล:** ค่าเริ่มต้น `claude-opus-5-5` ใช้ effort ต่ำ และเปิด server-side fallback กรณีโมเดลปฏิเสธ เปลี่ยนเป็นโมเดลที่ถูกกว่าได้ด้วย `ASSESSMENT_CLAUDE_MODEL`

**ข้อควรระวัง:**
- คีย์ที่เคยวางในแชทกับ AI ต้องเปลี่ยนใหม่หลังใช้งาน
- เครื่องที่ตั้ง `ANTHROPIC_AUTH_TOKEN` หรือ `ANTHROPIC_BASE_URL` ไว้ให้เครื่องมืออื่น (เช่น Claude Code ที่ต่อ proxy) ระบบประเมินไม่ใช้ค่าเหล่านี้ ตัวเชื่อมกำหนดให้ส่งตรงไป `api.anthropic.com` ด้วยคีย์ใน `.env.local` เท่านั้น เคยเจอปัญหานี้จริงเมื่อ 21 พ.ย. จึงมีชุดทดสอบกันไว้แล้ว
- ทดสอบกับคีย์จริงแล้วเมื่อ 21 พ.ย.: รอบฟังแยกเสียง (เสียง ก) ถูก 2 ผิด 1 ได้คำชม สิ่งที่ทำได้ดี สิ่งที่ควรฝึกต่อ และกิจกรรมที่บ้าน 2 อย่าง ตรงกับผลจริง ใช้เวลาประมาณ 20 วินาที

## 1. เมื่อได้คีย์ OpenAI จากพี่บาส

1. ขอให้พี่บาสสร้างคีย์ **แยกสำหรับโปรเจกต์นี้** และตั้งวงเงินรายเดือน ส่งทางช่องส่วนตัว ห้ามส่งในกลุ่มแชทหรือวางในแชทกับ AI
2. เปิด `.env.local` แล้ววางคีย์ต่อจาก `ASSESSMENT_OPENAI_API_KEY=` ไม่ต้องใส่เครื่องหมายคำพูด
   - คีย์ต้องขึ้นต้นด้วย `sk-` หรือ `sk-proj-` ถ้าขึ้นต้นด้วย `sk-or-` เป็นคีย์ OpenRouter ใช้ไม่ได้
   - อย่าใส่ใน `OPENAI_API_KEY` เพราะระบบประเมินไม่อ่านตัวนั้น และ `OPENAI_API_KEY` ในเครื่องเป็นของเครื่องมืออื่น
3. รัน `npm run assessment:check-openai` ต้องขึ้น `✓ คีย์ใช้งานได้` และ `✓ gpt-4o-transcribe`
4. รัน `npm run dev` ใหม่ แล้วเข้า `/platform/assessment` ด้วย `dev-platform@speechadventure.test`
   - ต้องเห็นสถานะ "OpenAI · ตั้งค่าแล้ว"
   - เปิด AI → บันทึกฉบับร่าง → เผยแพร่เป็นเวอร์ชันใหม่
5. สั่ง Agent Tester ทดสอบด้วยคีย์จริง โดยอนุญาตชัดเจนว่าให้เรียก OpenAI ได้ไม่กี่ครั้ง (agent จะไม่เรียกเองถ้าไม่ได้สั่ง)
6. ทดสอบด้วยเสียงผู้ใหญ่ (ไม่ใช่เสียงเด็ก) ในข้อพูดของ ป ก ม อย่างน้อยกรณีเหล่านี้:
   - พูดถูก
   - พูดพยัญชนะผิด เช่น บู แทน ปู
   - พูดซ้ำ
   - เงียบ
   - ปิดเน็ต
7. จดผลที่ AI ให้ เทียบกับที่ผู้ใหญ่ฟังตัดสิน

## 1B. เปลี่ยนเสียงพี่ปูให้เป็นธรรมชาติ

**ตอนนี้:** เสียงในห้องฝึกทั้ง 160 คลิปเป็นไฟล์ที่สร้างไว้ล่วงหน้าด้วยเสียง Microsoft "Premwadee" ฟังเป็นบอท ไม่มีบริการเสียงสดในแอป

**เลือกแล้ว (21 พ.ย.):** ใช้เสียง **Gemini "Sulafat" (อบอุ่น)** หลังฟังเทียบกับ Achernar (นุ่ม) และ Leda (สดใส)

**ทำไปแล้ว:**
- สคริปต์ `scripts/learning-studio/gemini-voice-samples.mjs` สร้างตัวอย่างเทียบเสียงเดิม ใช้คีย์ `VOICE_GEMINI_API_KEY` ใน `.env.local` ใช้ในเครื่องเท่านั้น เว็บไม่เรียก Gemini
- คำสั่งต้องใช้รูปแบบ AUDIO PROFILE / DIRECTOR'S NOTES / `#### TRANSCRIPT` ถ้าเขียนแบบ "Say warmly: …" โมเดลจะอ่านคำสั่งออกมาด้วย

**ยังไม่ได้ทำ:** สร้างครบ 160 คลิปแล้วแทนที่เสียงเดิม ติดเรื่องโควตาฟรีที่ได้ **10 คลิปต่อวันต่อรุ่น** ทางเลือกคือ
- เปิด billing ใน Google AI Studio แล้วสร้างครบในครั้งเดียว (ค่าใช้จ่ายน้อยมาก) หรือ

- ใช้ Gemini กับประโยคแนะนำและคำชม แล้วให้คนจริงอัดคำฝึก

**ก่อนใช้จริง:** มีคนฟังตรวจทุกคลิป โดยเฉพาะคำฝึก (ปา ปี ปู ฯลฯ) ว่าวรรณยุกต์และพยัญชนะถูก เพราะเด็กพูดตามเสียงนี้ จากนั้นนำเข้าด้วย `scripts/learning-studio/import-voices.mjs` ตามรหัสใน `public/learning-studio/audio/catalog.json`

**สิ่งที่ตามมา:** ปุ่ม "อ่านคำชมให้น้องฟัง" ในการ์ด Claude ถูกเอาออก เพราะคำชมเปลี่ยนทุกรอบและไม่มีคลิปให้เล่น จะใส่กลับได้ถ้ามีบริการเสียงแบบสร้างสด

## 4. เรื่องที่ต้องตัดสินใจ

- **"ทดลองตอบโดยไม่อัดเสียง":** ตอนนี้ระบบถือเป็นการจำลอง เก็บไว้ในเครื่องเท่านั้น ไม่เข้าคิวครูและไม่นับในสถิติ
  - กรณีผู้ใหญ่ฟังเด็กพูดสด ๆ โดยไม่มีไมค์ ผลจะไม่ถึงครู
  - ต้องตัดสินว่าควรมีปุ่ม "ผู้ใหญ่ฟังแล้ว" ที่ส่งผลเข้าศูนย์โดยไม่ต้องอัดเสียงหรือไม่
- **ใช้ Claude เพิ่มหรือไม่:** Claude ฟังเสียงไม่ได้ (รับได้แค่ข้อความและรูปภาพ) แต่ถ้ามีคีย์ ใช้ช่วยงานข้อความได้:
  - สรุปผลรายสัปดาห์ให้ผู้ปกครองและครู
  - แนะนำวิธีฝึกที่บ้าน
  - ร่างคำและประโยคสำหรับเสียงใหม่ ให้ผู้เชี่ยวชาญตรวจก่อนใช้
- **เกณฑ์รายระดับความยาก:** ตอนนี้เกณฑ์ชุดเดียวใช้ทั้ง 4 ระดับ ถ้าต้องการเกณฑ์แยกตามระดับต้องออกแบบเพิ่ม

## 5. ฐานข้อมูลในเครื่องของแต่ละคน (สำคัญ)

ถ้าใครเคยติดตั้ง migration ระบบประเมินจากบรานช์ `sky` เดิม ฐานในเครื่องจะบันทึกไว้ผิดเลข

- โชกุนเปลี่ยนเลขไฟล์ของเราจาก `20261116000100` และ `000200` เป็น `001300` และ `001400`
- แล้วใช้เลข `000100` และ `000200` กับไฟล์ join code ของโชกุนเอง
- ผลคือฐานในเครื่องจะเข้าใจผิดว่าไฟล์ของโชกุนติดตั้งแล้ว ทั้งที่ยังไม่ได้ติดตั้ง

**วิธีตรวจ:** ดูว่าในตาราง `supabase_migrations.schema_migrations` แถว `20261116000100` มี `name = central_assessment` หรือไม่ ถ้าใช่แปลว่าโดนปัญหานี้

**วิธีแก้แบบไม่ลบข้อมูล** (ที่ใช้ในเครื่องของ Peeranatz เมื่อ 18 พ.ย.):

1. สำรองฐานก่อนด้วย `pg_dump`
2. เปลี่ยนเลขในตาราง: `000100` → `001300` และ `000200` → `001400` (ไฟล์เดียวกัน แค่เปลี่ยนชื่อ)
3. ติดตั้งไฟล์ที่ยังขาดตามลำดับ (`000100`–`001200`, `001500`, `001600`) ทีละไฟล์ใน transaction แล้วบันทึกเลขลงตาราง
4. สั่ง PostgREST โหลด schema ใหม่ด้วย `NOTIFY pgrst, 'reload schema'`

ไฟล์ของโชกุนช่วง `000100`–`001200` ไม่แตะตารางประเมินเลย จึงติดตั้งหลังได้โดยไม่ชนกัน

อีกทางคือ reset ฐานในเครื่องแล้วติดตั้งใหม่ทั้งหมด แต่วิธีนี้ลบข้อมูลทดสอบทั้งหมด **ห้ามทำกับฐานจริงของพี่บาสเด็ดขาด**

## 6. การทดสอบ

```powershell
npm run assessment:test            # unit test ของเกณฑ์และตัวเชื่อม
npm run assessment:test-stages     # route จริง ครบ 432 กิจกรรม ตามตารางออกแบบ 12 ขั้น
npm run learning:test
npx tsc --noEmit
npm run build
```

ข้อมูลทดสอบหน้าเว็บ (เฉพาะ Supabase ในเครื่อง):

```powershell
node scripts/dev/seed-dev-accounts.mjs   # บัญชี *@speechadventure.test ทุกบทบาท
node scripts/dev/seed-test-school.mjs    # โรงเรียน ห้องเรียน เด็กโรงเรียน (น้องฟ้า) และเด็กครอบครัว (น้องบ้าน)
```

**Agent Tester** (`.claude/agents/assessment-tester.md`) เรียกได้ใน session ใหม่ของ Claude Code ด้วยข้อความเช่น "ใช้ assessment-tester ทดสอบระบบประเมินรวมหน้าเว็บ" agent ไม่แก้โค้ด ไม่ commit และไม่เรียก OpenAI จริงถ้าไม่ได้สั่ง

**ยังไม่ได้ทดสอบ:**
- การยืนยันผลในคิว "รอตรวจ" ของครู: ต้องให้คนอัดเสียงจริง 1 ครั้งในเบราว์เซอร์ ทำได้ตั้งแต่ตอนนี้ เพราะ AI ปิดอยู่และไม่มีเสียงถูกส่งออก
- เกณฑ์รายโรงเรียนผ่านหน้าเว็บ: ทดสอบแล้วในชุด stage matrix แต่ยังไม่ได้ลองผ่านหน้า `/school/assessment`
- การตรวจเสียงด้วย OpenAI จริง: รอคีย์
