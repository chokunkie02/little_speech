## ลูกศรที่ต้องเปลี่ยนใน Flowchart

1. **แอดมินระบบ** เพิ่มโรงเรียน → กรอกอีเมลผู้ดูแลคนแรก → เปิดรายละเอียดโรงเรียน → ส่งลิงก์คำเชิญผู้ดูแล
2. **ผู้ดูแลโรงเรียน** ตอบรับลิงก์ → เพิ่มห้อง → ส่งลิงก์เชิญครู → ครูตอบรับ → ผู้ดูแลจัดครูเข้าห้อง
3. **ครู** เพิ่มหรือค้นนักเรียน → กรอกอีเมลผู้ปกครอง → ส่งคำเชิญเข้ากล่องข้อความ ทำได้ก่อนผู้ปกครองเปิดบัญชี
4. **ผู้ปกครอง** เข้าระบบด้วยอีเมลที่ได้รับเชิญ หากโรงเรียนเตรียมบัญชีให้ ให้ไป **เข้าใช้ครั้งแรก** แล้วใช้รหัสเปิดใช้และตั้งรหัสผ่าน จากนั้นเปิดซองจดหมาย → เปิดคำเชิญ → ระบุความสัมพันธ์ → ตอบรับ → เปิดข้อมูลลูก
5. **กรณีแยก** ยังไม่เชื่อมเด็กให้เข้ากล่องข้อความและตั้งค่าได้ คำเชิญที่ยังรอตอบรับยกเลิกได้ บัญชีที่เชื่อมแล้วสามารถเชิญผู้ปกครองร่วมจากหน้าข้อมูลลูก คำขอแบบเดิมที่ยังรอครูตรวจให้วาดเป็นเส้นทางรอง
6. **ผลฝึก** เลือกเด็ก → เปิดห้องฝึก → เลือกแผนหรือกิจกรรม → ทำกิจกรรมและบันทึก → ดูสรุป → เปิดความก้าวหน้าหรือรายงานตามบทบาทและสิทธิ์

## กล่องที่ต้องเพิ่มใน System Architecture

- **เว็บ Next.js** แยกหน้าของ 4 บทบาท พร้อมแสดง `/inbox`, `/auth/activate` และ `/api/parent-activation` เป็นองค์ประกอบของเส้นทางผู้ปกครอง
- **Supabase Auth และ PostgreSQL** บัญชีที่เปิดใช้แล้วเข้าสู่ระบบตามบทบาท คำเชิญเก็บใน `invitations` และอ่านจากอีเมลของผู้รับ การกดรับคำเชิญใหม่บันทึกสิทธิ์ใน `child_access` ตามบัญชีและนักเรียน
- **สิทธิ์ตามโรงเรียนและห้อง** เชื่อม `organizations`, `organization_members`, `classrooms`, `classroom_teachers`, `classroom_students` และ `child_profiles` แสดงการค้นหาผ่านฐานข้อมูลตามสิทธิ์ของบทบาท
- **ห้องฝึกและรายงาน** แผนและรายละเอียดรอบใน Learning Studio ใช้พื้นที่เก็บข้อมูลบนเครื่อง ผลสรุปรอบที่รองรับส่งเข้าฐานข้อมูลผ่าน `src/features/learning-studio/useStudioResultSync.ts` เพื่อแสดงในหน้าผลที่มีสิทธิ์ ฟังก์ชันอัดฟังในห้องฝึกและสิทธิ์เปิดเสียงบันทึกจากระบบเดิมเป็นคนละเส้นทาง
- **พฤติกรรมการใช้งาน** `src/components/analytics/WebUsageTracker.tsx` ส่งสัญญาณการใช้งานของบัญชีที่ล็อกอิน แอดมินระบบอ่านยอดรวมจาก `get_platform_web_usage` แยกจากชุดข้อมูลตัวอย่าง `usageDemoData.ts`
- **การส่งข้อความ** วาดคำเชิญผู้ปกครองเป็นกล่องข้อความในเว็บ ส่วนคำเชิญครูและผู้ดูแลยังใช้ลิงก์ รหัสเปิดใช้ที่ผู้ดูแลสร้างส่งต่อให้เจ้าของบัญชีโดยตรง
