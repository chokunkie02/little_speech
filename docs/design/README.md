# Speech Adventure · Design Board

> **ใหม่ (22 พ.ย. 2569):** [ไวร์เฟรมหน้าฝึกสำหรับเด็ก เทียบก่อน/หลัง](wireframes/kid-practice.html) ทำตามฟีดแบ็กประชุมทีม เรื่องตัวหนังสือและปุ่มเยอะ ฟอนต์แบบเด็ก ตัวการ์ตูนพี่ปู และเกมโต้ตอบ 6 ขั้น พร้อมโหมด "เล่นด้วยกัน / เล่นเอง" ตามวัย ยังไม่ได้แก้เว็บจริง แบบใหม่ใช้ธีมสีม่วงกลางคืนของเว็บและภาพพี่ปูจริง (`wireframes/art/` สร้างด้วย `node scripts/design/export-art.mjs`) ภาพ "ปัจจุบัน" อยู่ใน `wireframes/before/` ถ่ายใหม่ได้ด้วย `node scripts/design/capture-practice-screens.mjs` (ต้องเปิดเว็บไว้) · ส่งให้คนอื่นดู: `node scripts/design/bundle-wireframe.mjs` ได้ไฟล์ HTML ไฟล์เดียวที่รวมภาพทั้งหมด (`.learning-runtime/share/kid-practice-share.html`)

เปิด [Speech-Adventure-PC-Design-Board.html](Speech-Adventure-PC-Design-Board.html) ในเบราว์เซอร์จากโฟลเดอร์นี้ เก็บโฟลเดอร์ `board/` ไว้ข้างไฟล์ HTML เพื่อให้ภาพและเมนูโหลดครบ บอร์ดเปิดได้จากไฟล์ในเครื่องและไม่ต้องรันตัวเว็บหรือฐานข้อมูล

- ดูชุดสีสว่าง สีมืด สีประจำขั้น และตัวอักษรจาก `src/app/globals.css` ห้องฝึกใช้สีจากระบบหลักผ่าน `src/features/learning-studio/host-theme.css`
- ดูภาพ UI จริง 96 ภาพ จัดตามบทบาทและลำดับงาน เปิดรายการตรวจเส้นทางเพื่อย้อนดูหน้าและทางเข้าเดิมครบ 27 เส้นทาง กดภาพเพื่อขยาย ใช้ลูกศรซ้ายขวาเปลี่ยนภาพ และกด Esc เพื่อปิด
- ใช้ Flow เชื่อมไปยังภาพแต่ละขั้น แผนภาพระบบแยกข้อมูลในเครื่อง บัญชี สิทธิ์โรงเรียน กล่องข้อความ ผลฝึก รายงาน และสถิติการใช้งาน
- เทียบ [Handoff ของโชกุน](../board-update-handoff.md) ได้ครบ 84 ข้อ มีภาพตามสถานะ 81 ข้อ และใช้ภาพอ้างอิงหรือชุดสีในข้อ 64, 69 และ 73

ภาพถ่ายจากโค้ด `9b33d85` บนจอ 1440 × 960 และ 390 × 800 โดยใช้บัญชีและข้อมูลสมมุติใน Supabase ผ่าน Docker ในเครื่อง ภาพเงื่อนไขพิเศษระบุไว้บนการ์ด รหัสเปิดใช้ถูกปิดบังในภาพ

ข้อมูลภาพและลิงก์ Flow อยู่ใน `board/data.js` ภาพจริงอยู่ใน `board/screens/` ชื่อไฟล์ตรงกับรหัสการ์ด เมื่อถ่ายภาพทดแทนให้ตรวจรหัสเส้นทาง ขนาดภาพ และเลข Handoff ที่อ้างภาพนั้น
